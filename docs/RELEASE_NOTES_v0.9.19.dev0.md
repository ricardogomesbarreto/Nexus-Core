# NEXUS CORE v0.9.19.dev0 — candidato de desenvolvimento

Esta versão de código permanece em Draft no PR #102. Não é tag nem release
estável. Conserva o assistente desktop local, PostgreSQL como banco de dados
do núcleo e serviços iniciados apenas sob demanda.

Inclui os cursos nativos, melhorias de voz e estudo, diagnóstico Linux e
adaptação Fedora descritos no README e nos guias da v0.9.19. Esta rodada
acrescenta receitas limitadas de dados, hashes/JSON/Base32, medição de CPU e
RAM e catálogo restrito de aplicativos instalados.

Limites e pendências verificáveis estão em
[LOCAL_CAPABILITIES_PROGRESS_v0.9.19.md](LOCAL_CAPABILITIES_PROGRESS_v0.9.19.md)
e na [auditoria das oito capacidades](OFFLINE_SUITE_STATUS_v0.9.19.md).
É necessária CI do SHA final e validação física em Ubuntu/Fedora antes de
promover a versão ou publicar uma tag.
